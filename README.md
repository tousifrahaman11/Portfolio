# Tousif Rahaman: Portfolio

React + Vite + Tailwind CSS + Framer Motion + Lucide.

## Run locally
    npm install
    npm run dev        # http://localhost:5173
    npm run build && npm run preview

## Things to fill in (all in src/data/content.js)
- PROJECTS[1].repo: Loan Chatbot GitHub URL (currently a marked placeholder)
- PROJECTS[*].demo: live demo URLs (button is hidden until set)
- PROJECTS[*].image: e.g. '/screenshots/resume-analyzer.png' (put images in public/screenshots/)
- Contact form: copy .env.example to .env and set VITE_FORM_ENDPOINT (e.g. a Formspree URL). Without it the form stays disabled.
- Resume: replace public/Tousif_Rahaman_Resume.pdf to update it.
